# Changelog

## 0.1.0 — Initial public preview

- VS Code trainer panel using the existing Python engine and three-panel interface.
- 159 randomized pandas, NumPy, and quantitative-data exercises across nine packs.
- Automatic grading, progress tracking, hints, and worked explanations.
- Initial open-source documentation, reproducible tests, and build instructions.

**Known limitation:** the extension requires the DataGym project folder and a configured Python environment. This is not yet a self-contained Marketplace installation.
